FoundIt – Campus Lost & Found (DevOps Capstone)
===============================================

Name: Anshul Mohanty    Roll No: 24BCS10191    Section: A

FoundIt is a campus lost & found board: students report items they **lost** or **found**, others browse
and filter them, and an item moves `OPEN → CLAIMED → RETURNED`. The app is small on purpose: the project
is the DevOps layer around it. That layer covers tests, containers, a CI/CD pipeline with a security gate,
Kubernetes via Helm, monitoring, autoscaling, GitOps, and AWS infrastructure built with Terraform.
